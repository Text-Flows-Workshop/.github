# Text Flows Workshop

> Text is not just a medium — it's the **interface** for cognition with LLMs.

Effective work with AI depends on a skill almost nobody teaches: **moving
text well** — extracting, transforming, splitting, recombining, and
versioning the words that flow between human and machine. Not prompt
engineering: the layer *under* it.

This organization publishes the complete, reusable materials for the
**Text Flows** workshop — slides, participant worksheet, facilitation
guide, hands-on exercises, installation guides, and worked example
workflows — under **CC BY 4.0**, so any AI-literacy effort can adopt and
adapt them.
